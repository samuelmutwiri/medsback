📡 API Endpoints Reference
Authentication

POST /api/auth/register/- Register new user
POST /api/auth/login/- User Login
POST /api/auth/logout/- Logout user
GET /api/auth/user/- Get current user
GET /api/auth/csrf/- Set CSRF cookie
GET /api/profile/- Get current user profile
PATCH /api/profile/- Update current user profile

Courses

GET /api/courses/- List all courses
POST /api/courses/- Create course (CEO only)
GET /api/courses/{id}/Get course details
PUT /api/courses/{id}/- Update course (CEO only)
DELETE /api/courses/{id}/- Delete course (CEO only)
GET /api/courses/search/?q=<query>&type=<type>- Search courses

Enrollments

GET /api/enrollments/- List enrollments
POST /api/enrollments/- Create enrollment
GET /api/enrollments/{id}/Get enrollment details
PATCH /api/enrollments/{id}/update_progress/- Update progress

Payments

GET /api/payments/- List of payments
POST /api/payments/- Create payment
GET /api/payments/{id}/- Get payment details
GET /api/payments/statistics/- Get payment stats (CEO only)

Certificates

GET /api/certificates/- List certificates
POST /api/certificates/- Issue certificate (Instructor/CEO)
GET /api/certificates/verify/?certificate_id=<id>- Verify certificate

Exams

GET /api/exams/- List exams
POST /api/exams/- Create exam (Instructor/CEO)
GET /api/exams/{id}/- Get exam details

Exam Results

GET /api/exam-results/- List results
POST /api/exam-results/- Create result
GET /api/exam-results/{id}/- Get result details

Notifications

GET /api/notifications/- List notifications
POST /api/notifications/{id}/mark_read/- Mark as read
POST /api/notifications/mark_all_read/- Mark all as read
GET /api/notifications/unread_count/- Get unread count

Dashboard

GET /api/dashboard/stats/- Get dashboard statistics (role-aware)

Gallery (MoU Gallery + Clinical Research Gallery)

GET /api/gallery/?type=mou|clinical-research- List photos (public)
POST /api/gallery/- Upload photo (CEO only, multipart: type, image, caption)
DELETE /api/gallery/{id}/- Remove photo (CEO only)

Schedules (specialist course scheduling & calendars)

GET /api/schedules/- List schedules (scoped to role)
POST /api/schedules/- Create a class schedule (Instructor/CEO)
PATCH /api/schedules/{id}/- Update a schedule (Instructor/CEO)
DELETE /api/schedules/{id}/- Delete a schedule (Instructor/CEO)

Grades (specialist marking / gradebook)

GET /api/grades/- List grades (scoped to role)
POST /api/grades/- Record a grade (Instructor/CEO)
PATCH /api/grades/{id}/- Update a grade (Instructor/CEO)

Feedback

GET /api/feedback/- List feedback (scoped to role)
POST /api/feedback/- Give feedback (Instructor/CEO)

Attendance

GET /api/attendance/?course=<id>- List attendance (scoped to role)
POST /api/attendance/- Mark attendance (Instructor/CEO)

Allocations (CEO assigns specialists to courses)

GET /api/allocations/- List allocations (Instructor/CEO)
POST /api/allocations/- Allocate a specialist to a course (CEO only)

Users Directory (CEO-only — backs CSV/PDF/Word exports)

GET /api/users/?role=student|instructor|ceo- List users

WebSocket

ws://localhost:8000/ws/notifications/- Real-time notifications
  (joins group `notifications_<user_id>`; pushed to on enrollment, payment,
  certificate issue, grade, feedback, and allocation)
